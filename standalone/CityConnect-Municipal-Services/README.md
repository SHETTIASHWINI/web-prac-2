# CityConnect – Municipal Services

A complete, self-contained HTML, CSS, and JavaScript municipal services portal with real-life photography, a spoken English Audio Guide (`speechSynthesis`), and a playable municipal operations video.

## How to Run in VS Code

1. Unzip `CityConnect-Municipal-Services.zip` and open the `CityConnect-Municipal-Services` folder in **VS Code** (`File -> Open Folder...`).
2. **Option A (Recommended):** Install the **Live Server** extension in VS Code, right-click `index.html`, and click **Open with Live Server** (runs cleanly on `http://127.0.0.1:5500`).
3. **Option B (No extensions):** Double-click `index.html` in your file explorer, or run `npx serve .` in the VS Code terminal.

## Folder Structure

- `index.html` – Semantic HTML5 portal page
- `css/style.css` – Responsive municipal styling
- `js/main.js` – Audio Guide speech engine, video controls, photo lightbox, and form validation
- `assets/images/` – Verified Wikimedia Commons & public-domain municipal photographs
- `assets/video/` – Playable MP4 municipal operations video (`cityconnect-in-action.mp4`)
